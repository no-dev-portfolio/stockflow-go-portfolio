## 監査の注意情報

[GO-2026-5932](https://pkg.go.dev/vuln/GO-2026-5932)は`golang.org/x/crypto/openpgp`が保守されず安全でない設計である旨の注意情報です。依存モジュールx/crypto v0.58.0に含まれますが、当作品はopenpgpをimport・呼び出ししていません。修正済みバージョンはN/Aと表示されます。依存更新前に検出した到達可能な指摘は依存更新後に解消しました。コンテナOS全体の脆弱性監査を実施したとはしていません。

## 再実行

```sh
docker compose --profile test run --build --rm tests
```

このビルドでフロントエンドを型検査・ビルド・テストし、実行でGoの整形・静的解析・競合検出付きテストを行います。`scripts/check.sh`はDB接続先なしでは失敗します。通常の`go test`だけをDBなしで実行すると統合テストがskipされるため、上記手順を使用してください。

```sh
# Go開発環境で依存監査を追加する場合
go install golang.org/x/vuln/cmd/govulncheck@latest
govulncheck -show verbose ./...
```

GitHub Actionsの定義はありますが、リモート実行結果ではありません。ログは[evidence](evidence/)に保存しています。画像は実ブラウザーでのローカル確認時に取得しました。初期データと操作後データの画像が混在するため、件数が異なります。
