## 改修箇所の確認

- healthはLISTEN_ADDRから接続先を構成し、IPv4・IPv6の全インターフェース指定をループバックへ変換する。未指定は8080。URL検査と実HTTPの200/503検査が成功。
- expiredへの確定・取消再送は409 expiredを返す。回帰試験でversion・在庫・Outboxの追加変更がないことを確認。
- 旧PR-01は在庫行ロック取得後に期限を再判定し、待機中の期限超過を出荷しない。
- 旧PR-02はContent-Typeを厳密に解析し、不正なJSON類似メディアタイプを拒否する。
- 確定済み・取消済みへの同じ最終操作を、古い正のversionでも成功として返す仕様は維持。
